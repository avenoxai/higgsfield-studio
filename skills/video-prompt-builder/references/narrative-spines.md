# Narrative Spines — 7 Structures for 4-7 × 8s Videos

Each 8-second clip is a separate Seedance generation. The spine determines which clip does what narrative job. Pick by video type.

---

## 1. Crypto-Launch Spine (6 clips / 48s) — DEFAULT for token/protocol launches

| Clip | Job | Generated | On-screen |
|---|---|---|---|
| C1 | Ticker-tease — one visual that IS the thesis | 8s | 6-7s |
| C2 | World/Vibe — set the enemy, paint the tribe | 8s | 5-6s |
| C3 | Mechanic/Differentiator — show not tell | 8s | 3-4s + punctuation |
| C4 | Social proof / moment — terminal, chart, fill | 8s | 4-5s |
| C5 | Hero reveal — ticker lockup, full payoff | 8s | 7-8s |
| C6 | Tag — CTA / loop-back / CA | 8s | 3-4s |

**Anchor:** Hero-late (C5). Optional double-anchor with C1 tease.
**Loops:** Loop A (what is this?) opens C1, partially resolves C3, closes C5. Loop B (what do I do?) opens C3, closes C6.

## 2. PAS / PASTOR (4-5 clips) — Direct response

- **Problem** (C1) — name the pain
- **Agitation** (C2) — make it visceral
- **Solution** (C3) — show the counter
- **Transformation** (C4, optional) — before/after
- **Offer/Response** (C5) — CTA

**Anchor:** Hero-late (the transformation or offer).
**Loops:** Loop A (can I escape this pain?) opens C1, closes C4/C5.

## 3. 7-Shot Spec-Ad Spine (6-7 clips) — Brand films, cinematic product reveals

- **Establishing** (C1) — world, setting, atmosphere
- **Character** (C2) — who we follow
- **Tension** (C3) — what's at stake
- **Inciting moment** (C4) — signature moment
- **Climax** (C5) — hero beat
- **Resolution** (C6) — relief/payoff
- **Tag** (C7) — logo / CTA

**Anchor:** Hero-mid (C4 inciting OR C5 climax — both strong positions).
**Loops:** Loop A (what happens?) opens C2, closes C5. Loop B (will they?) opens C3, closes C6.

## 4. AIDA Compressed (4 clips / 32s) — Short product teaser

- **Attention** (C1) — pattern interrupt
- **Interest** (C2) — why this matters
- **Desire** (C3) — transformation glimpse
- **Action** (C4) — CTA

**Anchor:** Hero-late (C4) or hero-early (C1).
**Loops:** One loop only — "what is this?" opens C1, closes C3.

## 5. Pixar Story Spine Compressed (5 clips / 40s) — Transformation, founder arcs

- **Once upon a time** (C1) — baseline world
- **Every day** (C2) — the routine
- **Until one day** (C3) — the disruption
- **Because of that** (C4) — the change
- **Until finally** (C5) — the new state

**Anchor:** Hero-late (C5).
**Loops:** Loop A (what disrupts?) opens C2, resolves C3. Loop B (what becomes?) opens C3, closes C5.

## 6. Music-Video Build + Drop (5-7 clips) — When you have a locked track

- **Tension build** (C1-C4) — shots synced pre-drop, increasing intensity
- **Drop** (C5) — signature image lands on the beat drop
- **Afterglow** (C6-C7) — release/resolution shots

**Anchor:** The drop shot (C5).
**Loops:** Musical tension IS the loop. Drops and resolutions mirror the track.

## 7. Philosophy/Stoicism Arc (5 clips / 40s) — Wisdom content, male self-improvement

- **Hook with weight** (C1) — one image, one provocation. Marble. Statue. Candle. Text overlay: one claim.
- **The enemy** (C2) — state of modernity, screens, softness, "them"
- **The way** (C3) — discipline in action, cold plunge, barbell, books
- **The wisdom** (C4) — Marcus/Seneca/Epictetus quote, VO over slow push-in on stone
- **Call to self** (C5) — close-up on eyes. Text: "choose." / "begin." / "today."

**Anchor:** Hero-late (C4 or C5).
**Loops:** Loop A (what is the way?) opens C1, escalates C2-C3, resolves C4, closes C5 on the viewer's decision.

---

## How to Pick

| If the video is... | Use spine |
|---|---|
| Token / protocol launch | Crypto-Launch Spine |
| Product problem → solution ad | PAS |
| Brand film, premium product, cinematic | 7-Shot Spec-Ad |
| Quick teaser, 20-30s | AIDA Compressed |
| Founder/brand origin story | Pixar Spine |
| You have a track locked | Music-Video Build + Drop |
| Philosophy / stoicism / masculine-improvement | Philosophy Arc |

---

## Anchor Placement Strategy

- **Hero-early (C1 or C2)** — trailer energy. Works for paid social where the first 3s determines survival. Risk: nothing left to climb toward.
- **Hero-middle (C3 or C4)** — Pixar/7-shot inciting position. Balanced. Rarely the most memorable.
- **Hero-late (C5 of 6, C6 of 7)** — cinematic reveal. Builds to the moment. DEFAULT for launches, product reveals, philosophy content.
- **Double-anchor (C1 + C5)** — echo structure. C1 plants visual; C5 pays it off transformed. Highest-effort, highest-impact. Standard for TikTok loop-back.

---

## Loop Architecture Rules

1. At any moment in the video, at least one unresolved loop must be live.
2. Minimum 2 loops for a 6+ clip video. 3 loops for 7 clips.
3. Loops don't all close at the same time. Stagger resolution.
4. The final loop may stay partially open — "what happens next?" as the tag question. This drives rewatch and comment engagement.
5. Open loop A in C1; open loop B mid-video (C3 or C4); if 3 loops, open C in C5. Resolve A in C5, B in C6, C as question in C6 or post-CTA.

---

## The Signature Moment Placement

Every video has ONE hero image — the frame that IS the piece. Which clip carries it determines the anchor strategy.

Write the signature moment FIRST, before any clip prompt:
- "The viewer sees X at the climax."
- Everything before X sets it up. Everything after X lands it.

If you can't describe the signature moment in one sentence, stop and figure it out before continuing. No signature = no hero = no shareable frame = lost video.
