# Framework Overview — The 4-Layer Scroll-Stop Stack

Every video must pass through all four layers in sequence. Skipping a layer guarantees scroll-loss regardless of how well the other three are executed.

## The Stack

```
LAYER 1 — PSYCHOLOGY
  Universal mechanisms the brain cannot ignore.
  Orienting response, FFA hijack, Loewenstein info-gap, Zeigarnik,
  parasocial imprint, variable-ratio reward, tribal signaling.
         ↓
LAYER 2 — AUDIENCE
  Universal mechanisms translated into tribe-specific triggers.
  CT insider vocabulary ≠ health-woman aesthetic ≠ stoic-masculine austerity.
  Same mechanism, different surface.
         ↓
LAYER 3 — NARRATIVE
  Multi-clip story spine: 4-7 × 8s.
  AIDA / PAS / 7-shot / crypto-launch / music-video / philosophy-arc.
  Loop architecture: where loops open, escalate, partially resolve, close.
  Anchor placement: hero-early / hero-late / double-anchor.
         ↓
LAYER 4 — EXECUTION
  Seedance 2.0 on Higgsfield.
  Prompt craft (60-100 word sweet spot, physics-not-captions, 5-layer stack).
  Reference slots (up to 9: start frame + character anchors + style + environment).
  Stitching (audio-first J-cut, whip pan, through-object, last-frame-to-first chain).
  Content-filter preflight.
```

## Cross-Layer Multipliers

Where the layers multiply each other — the high-leverage compounds:

### 1. Frame 1 trigger × Tribe encoding = Surgical Hook
Not "face to lens" — but "face to lens rendered in the aesthetic code the tribe reads as theirs." A CT video opens on 3am terminal glow + single lit face over mechanical keyboard. A stoicism video opens on marble statue half-lit in B&W chiaroscuro. Same mechanism (FFA hijack + luminance anomaly), different tribe signal.

### 2. Loop stacking × Clip-position weighting = Retention Curve
Loop A opens in C1 (the promise). Loop B opens in C3 (danger-zone reset — where 50-70% of retention is normally lost). Loop A partially resolves in C5 (hero). Loop B closes in C6 tag. Never all loops closed simultaneously. Viewer exits with an open thread still running → rewatch likelihood ↑.

### 3. Parasocial imprint × Audio-first editing = Belief
Intimate setting + founder's imperfect VO + match-cut seam-hide = "this is a real human talking to me, not AI-generated slop." Audio-first editing hides AI-video seams; parasocial imprint hides AI-provenance tells. Stacked, they kill the "this is AI" detection reflex.

### 4. Enemy framing × Signature hero-late = Tribal Climax
C1-C3 paints the enemy in the tribe's vocabulary (TradFi, toxic diet culture, soy/NPC consumers, Web2 SaaS sheen). C4 shows the counter forming. C5 hero reveal is the weapon — the product, the transformation, the drop. Tribalism circuit is older and stronger than any persuasion circuit. Tribal videos outperform neutral videos by wide margins.

### 5. Variable-reward rhythm × Pacing S-curve = Unscroll-able
The 1-2s punctuation inserts between 8s clips are where unpredictable micro-payoffs land. The pacing S-curve (slow front, fast mid, held hero, quick tag) means the viewer can't predict where the next hit comes. Dopamine system stays engaged. This is why Hormozi-style edits work — it's variable-ratio reinforcement inside the clip.

## The "Frame 1 Is Everything" Rule

If you only have 15 minutes to plan a video, spend 14 on Frame 1. Every other decision downstream is noise compared to whether Frame 1 triggers the orienting response and encodes the tribe.

**Frame 1 must simultaneously hit:**
- Subcortical attention trigger (face/motion/anomaly/pre-verbal)
- Tribal identity signal (aesthetic code the audience reads as "for me")
- Open loop (curiosity gap that feels 20-40s from resolution)
- Platform-appropriate aspect/composition (9:16 vertical with action in center-frame for CT/TikTok)

If Frame 1 fails, nothing the rest of the video does matters. Save the hero for C5 but spend like an adult on C1.

## Anti-Framework Patterns

Things that undo the framework:

- **Broad messaging** — "something for everyone" = for no one = no tribe = no identity trigger → scroll
- **Logo/intro cards** — viewer grants attention to humans and content, not brands. Burning the C1 budget on a logo is catastrophic.
- **Production polish without parasocial anchor** — clean ≠ trusted. Polish without a human signal reads as corporate slop.
- **All loops closed by the hero clip** — nothing held back for the final clip to carry. The tag shot becomes dead air.
- **Flat pacing** — 7 clips of equal on-screen duration = AI slideshow death.
- **Narrating what the visual already shows** — VO should extend, not duplicate. Redundancy halves bandwidth.
- **Waiting until the end to reveal the tribe** — if the tribe isn't encoded in the first frame, the non-tribe viewer is already gone and the in-tribe viewer wasn't convinced you knew them.
- **Judging clips in isolation** — always judge against neighbors. A perfect C3 that doesn't match C2 and C4 is worse than three "B+" clips that cohere.
- **Changing multiple prompt variables between rolls** — you lose signal on what helped. One variable per iteration.

## How to Use This Framework Operationally

1. **Write the audience profile first.** Even if you think you know the audience, write it out in 5-8 sentences. Capture: what they call themselves, what they mock, what they consider insider knowledge, what aesthetic signals "for me," what status looks like.

2. **Write the signature moment second.** One sentence: "The viewer sees X at the climax." Every prior decision either sets this up or it's cut.

3. **Design the loop architecture third.** Draw the timeline. Mark where each loop opens, escalates, partially resolves, closes. A 6-clip video should have 2-3 loops active simultaneously by the mid-point.

4. **Then write Frame 1.** Only after 1-3. Frame 1 must serve the audience profile, tease the signature, and open at least one loop.

5. **Write the clips from the hero outward.** Write the hero clip first (C5 usually), then C1 as its echo/tease, then fill C2-C4 as the build, then C6 as the tag/loop-back.

6. **Stitch plan comes before prompt refinement.** Pick transitions and audio first. This changes what the end/start of each clip needs to be. Writing prompts then realizing you need a whip-pan exit means rewriting.

7. **Content-filter preflight before generation.** Scan each prompt for triggers (age descriptors, branded IP, celebrity likeness, body-context stacks). Route risky ones through the bypass protocol.

## When the Framework Breaks (and You Need to Escalate)

The framework is tuned for 4-7 clips × 8s on Seedance 2.0. It breaks down for:

- **Single-clip videos** (just use the Seedance mechanics layer; narrative spine is overkill)
- **60s+ essay-style videos** (need YouTube-style retention editing, not short-form scroll-stop — use the vault's AI Short Film Guide reference)
- **Dialogue-heavy scenes** (Seedance handles dialogue poorly; escalate to Hailuo 2.3 or Veo 3.1)
- **Hyper-realistic human faces in wide shots** (AI-detection trigger; redesign to avoid or use Path A embrace-the-aesthetic)
- **Content filter hard-blocks after 3 rewrites + Chinese bypass** (platform escape to Wan 2.5/2.6 — out of scope for this skill)

If you hit these, tell the user and suggest the escalation path.
